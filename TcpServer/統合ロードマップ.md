# Phase 4：CUDA

### 13〜16週

ここで初めてCUDAを本格的に入れます。

ただしLLMにはまだ行きません。

まず簡単な、

- vector add
- matrix multiplication
- image processing

から。

例えば、

```
CPU版
↓
CUDA版
↓
Benchmark
```

を作ります。

測定：

```
CPU        120 ms
CUDA        18 ms
CUDA+copy   31 ms
```

ここで、

> GPU計算自体は速いけど転送コストがある

という感覚を身につけます。

あなたの既存GPU経験ともかなりつながる部分です。

---

# Phase 5：ML Inference

### 17〜20週

ここでPyTorchを入れます。

ただしモデル学習に何か月も使いません。

今回の目的は、

**ML ResearchではなくML Systems**

だからです。

例えばPyTorchで既存モデルを動かす。

↓

ONNXへexport。

↓

ONNX Runtime。

```
PyTorch
   ↓
ONNX
   ↓
ONNX Runtime CPU
   ↓
ONNX Runtime GPU
```

比較：

```
PyTorch CPU       25 ms
ORT CPU           17 ms
ORT CUDA           5 ms
```

そして、

- warmup
- batch
- latency
- throughput
- VRAM
- precision

を見る。
