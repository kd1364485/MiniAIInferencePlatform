# 提出動画の台本（30 秒以内・コマンドを実行して見せる）

この PC の WSL（Ubuntu）で、C++ 推論サーバーを **CPU 版**で動かす（Docker / GPU は使わない）。
ナレーションで「GPU で推論」とは言わない（この PC では CPU で動かしているため）。

---------------------------------------------------------------------

## A. 録画の前の準備（所要 約 2 分）

### A-1. ターミナルを 2 つ用意する
1. Windows Terminal（または PowerShell）を開く
2. 下のコマンドを打って、WSL に入る
   ```
   wsl -d Ubuntu
   ```
3. 画面を左右に分割する: `Alt + Shift + +`（Windows Terminal の場合）。
   分割できなければ、もう 1 つウィンドウを開いて、また `wsl -d Ubuntu` と打つ
4. 左をターミナル 1、右をターミナル 2 とする

### A-2. 両方のターミナルで、作業フォルダに移動する（打つだけ。Enter はまだ押さない手順もある）
**ターミナル 1（左）**
```
cd ~/infer-demo
```
Enter を押す。続けて、次を**打つだけ**（Enter は押さない）:
```
./start_server.sh
```

**ターミナル 2（右）**
```
cd ~/infer-demo
```
Enter を押す。続けて、次を**打つだけ**（Enter は押さない）:
```
./demo.sh
```

→ 録画中は、それぞれ Enter を押すだけになる（タイピングの時間を節約）

### A-3. 画面を整える
- 文字を大きくする: `Ctrl` を押しながらマウスホイール（読めるサイズまで）
- 通知やほかのウィンドウを閉じる
- パスワードや個人情報が映っていないことを確認する

### A-4. 録画しないで 1 回、通しで練習する（必須）
1. 左で Enter → サーバーが起動する（`infer_server: port 8080 ...` が出るまで待つ）
2. 右で Enter → 約 10 秒で結果が出る
3. 左で `Ctrl + C` → サーバーが止まり、統計が出る
4. 練習が終わったら、左右とも、次のコマンドを**打つだけ**の状態に戻す（A-2 の「打つだけ」の行）
   - 左: `./start_server.sh`
   - 右: `./demo.sh`
   - 練習後にサーバーが残っていたら、`pkill -x infer_server` を打ってから、戻す

---------------------------------------------------------------------

## B. 録画中の操作（0:00〜0:30）

録画を開始する: `Win + Alt + R`（Xbox Game Bar）または OBS の録画ボタン。録画開始から 1〜2 秒後に始める。

| 時間 | 操作 | 画面に出るもの | 話すこと |
|---|---|---|---|
| 0:00 | **左（ターミナル 1）で Enter** | `warming up (provider=cpu, max_batch=32)...` → `infer_server: port 8080, model=..., workers=2, ... max_batch=32, provider=cpu ...` | 「C++ で作った、AI 推論サーバーです。ONNX Runtime で推論します。」 |
| 0:07 | サーバーの起動行（`infer_server: port 8080 ...`）が出たのを確認して、**右（ターミナル 2）で Enter** | `$ curl localhost:9100/healthz` → `ok` | 「100 台のクライアントから、同時に負荷をかけます。」 |
| 0:10 | 負荷が走っている（約 8 秒待つ。画面は止まって見える） | （待ち） | 「リクエストをバッチにまとめて、推論します。」 |
| 0:18 | 結果が出る | `connections: 100 ... req/s: 約2万` と `latency(us): p50=... p95=... p99=...` | 「1 秒あたり約 2 万件、レイテンシも測っています。」（実際の数字を見て読む） |
| 0:22 | メトリクスが出る | `infer_requests_total ...` と `infer_batches_total ...` | 「処理件数は、メトリクスとして公開しています。」 |
| 0:25 | **左（ターミナル 1）で `Ctrl + C`** | `requests=... avg_batch=... ` の統計 | 「Phase 8 まで終わりました。次は Kubernetes です。」 |
| 0:30 | 録画を終了する | | |

合計のナレーション: 約 140 字。

### 時間がオーバーしそうなとき
- 0:10 の「リクエストをバッチにまとめて、推論します。」を省く
- 負荷を 8 秒から 5 秒に縮める: ターミナル 2 を開いて、`sed -i 's/ 100 8 dummy/ 100 5 dummy/' ~/infer-demo/demo.sh` を実行し、あとで確認する（この変更後の最初の 1 回は、練習で試すこと）

### 起動の待ち時間が長いとき（0:00〜0:07 が間延びするとき）
- 練習時にサーバーを起動したまま止めずに、左は何もせず、0:00 から**右の Enter だけ**で始める
- この場合、0:00 のナレーションを「C++ で作った、AI 推論サーバーです。今、動かしています。」にして、すぐ右で Enter

---------------------------------------------------------------------

## C. 録画のあと（必須の確認）
1. 動画を再生して、**30 秒以内**か確認する
2. 音声が入っているか確認する
3. 文字が読めるか確認する
4. パスワードや個人情報が映っていないか確認する
5. 失敗したら、A-4 の 4 に戻って、もう一度録る（何回やり直してもよい）

## D. 録画の方法（Windows）
- Xbox Game Bar: `Win + Alt + R` で開始、もう一度で終了。**Windows Terminal のウィンドウをクリックして選んだ状態**で押す。保存先は「ビデオ → キャプチャ」
- OBS Studio: 「画面キャプチャ」を追加し、マイクを有効にして、録画開始

## 参考: この PC での実測（練習時の目安）
- 100 接続・5 秒: 23,613 req/s、p50 4,135us、p99 5,176us
- `/healthz` は ok、`/metrics` の件数は bench の完了数と一致、平均バッチ 約 32
- 数字は実行のたびに少し変わる。**読み上げるときは、画面の数字を見て丸める**（例: 「約 2 万件」）
